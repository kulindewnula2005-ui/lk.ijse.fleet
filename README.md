#lk.ijse.fleet
## Project Description
This is a Java console-based Fleet Rental Management System developed using Object-Oriented Programming (OOP) concepts.

## Main Features
- User Login
- Vehicle Management
- Customer Management
- Rental Agreement Management
- Vehicle Availability Management
- Rental Status Management

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- NetBeans IDE

## Requirements
- Java JDK 25 or later

## How to Run
1. Open the project in NetBeans IDE.
2. Open the Main.java file in the package lk.ijse.fleet.
3. Run the Main.java file.
